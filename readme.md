=====================
第一部分 PRD 产品需求文档
=====================
1.项目概述
1.1项目简介
《碎晶突围》是移动端单手操作休闲割草游戏。玩家操控发光菱形晶体，在晶洞场景躲避晶体怪物，击杀怪物获取经验升级，升级弹出3选1技能。核心机制：怪物死亡触发晶体碎裂爆炸，爆炸碎片命中其他怪物可产生连锁爆炸，形成全屏清场视觉爽感，适合短视频录屏传播。游戏为单机离线，无PVP，无实时网络对战。

1.2核心目标
1.验证核心玩法循环：移动→打怪→捡经验→升级选技能→技能叠加→连锁爆炸清场
2.打造短视频高光片段：引力漩涡+碎裂引爆组合，实现多米诺连锁爆炸
3.原型美术全部使用Godot内置Polygon2D+Shader，不依赖外部图片素材，快速开发，保证风格统一
4.降低挫败感：对局失败同样发放永久货币，用于局外永久属性养成

1.3用户画像
碎片化摸鱼用户，一局2~3分钟，单手触屏操作；刷短视频看到爆炸高光片段吸引进入游戏。

1.4一局游戏规则
单局倒计时：180秒，存活到时间结束即通关；血量归零则本局失败。
玩家自动攻击，玩家仅控制移动（手指滑动拖动角色）。
怪物自动寻路向玩家移动，碰撞玩家造成伤害。
击杀怪物掉落晶粒，拾取增加经验；经验条满触发升级，弹出3选1技能面板。
技能可重复拾取，重复获得同一技能会提升该技能等级，增强效果。

2.游戏核心玩法
2.1局内循环
触屏滑动控制角色移动 → 自动发射晶刺攻击怪物 → 击杀怪物掉落晶粒 → 拾取晶粒涨经验 → 升级弹出3选1技能 → 技能叠加增强 → 怪物扎堆触发连锁爆炸 → 存活到倒计时结束通关

2.2技能列表（原型仅实现8个，升级随机3选1，同技能重复获取升级）
攻击&连锁爆炸（短视频高光核心技能）
1.晶刺弹射：晶刺击中怪物后弹射到下一只怪物；等级提升增加弹射次数、弹射距离。
2.碎裂引爆【招牌核心技能】：怪物死亡时产生爆炸，碎片飞出命中其他怪物，被命中怪物也触发爆炸，形成连锁；等级提升爆炸半径、碎片数量。
3.晶域扩散：玩家周围持续环形伤害场，持续切割靠近怪物；等级提升范围与伤害。

生存类
4.晶盾：周期性生成护盾，抵挡一次伤害；等级减少冷却时间。
5.瞬闪位移：手动点击按钮短距离冲刺闪避；等级减少冷却、增加冲刺距离。

增益强化
6.高速结晶：提升晶刺发射频率。
7.晶刺增重：提升晶刺伤害，增加击退怪物效果。
8.引力漩涡：周期性生成引力场，自动吸附范围内怪物向中心聚集；等级提升引力范围、吸力强度。
最强组合：引力漩涡 + 碎裂引爆，怪物聚成一团，触发全屏连锁爆炸（短视频主素材）

2.3怪物设计（原型3种）
1.小晶怪（三角形）：血量低、移动快、数量多，基础经验。
2.大晶兽（五边形）：血量高、移动慢，击杀获得大量经验。
3.晶核BOSS（大六边形）：120秒固定刷新1只，高血量，击杀大量经验+临时增益buff。

2.4局外永久养成（全局永久生效，跨局保留）
每局结束（通关/失败）奖励晶核货币。
4项永久强化，消耗晶核升级：
1.初始血量 +5
2.初始攻击 +2
3.晶粒拾取范围扩大
4.开局获得1级随机基础技能

2.5UI界面清单
1.主菜单：开始游戏、永久强化面板、图鉴面板
2.局内HUD：血量条、倒计时、经验条、晶核货币显示、瞬闪技能按钮
3.升级弹窗：3张技能卡片，点击选择一个技能
4.结算面板：本局结果（通关/失败）、本局连锁爆炸最高连击数、获得晶核数量、返回主菜单按钮
5.永久强化面板：4项属性，消耗晶核升级

2.6音频与视觉需求（原型版）
1.视觉：全部几何多边形，自发光晶体Shader；爆炸时屏幕震动、闪光，粒子为多边形碎片。
2.音效：晶刺发射声、怪物破碎声、连锁爆炸清脆晶体碎裂音效、升级提示音。
3.BGM：轻快电子背景音乐。

2.7胜利失败判定
胜利：倒计时到0，玩家血量大于0 → 通关结算。
失败：玩家血量归零 → 失败结算，依旧发放晶核奖励。

3.非功能需求
1.移动端触屏优先，优先竖屏。
2.WebGL打包性能优化，控制同屏怪物上限，防止手机卡顿。
3.单机游戏，不需要后端服务器，存档保存在浏览器本地存储LocalStorage。
4.原型阶段禁止引入外部图片贴图，全部使用Godot原生节点+Shader实现。

4.上线相关（原型阶段暂不开发）
原型不做广告、分享、付费；仅本地存档。

5.风险与约束
1.限制同屏怪物数量上限，防止WebGL性能爆炸。
2.连锁爆炸不能无限递归，设置最大连锁层数，避免死循环卡死游戏。
3.UI文字大小适配手机屏幕，触屏按钮尺寸足够大，防止误触。

第二部分 SDS 方案设计文档
=====================
1.技术栈
引擎：Godot 4.x
脚本语言：GDScript
平台：WebGL，用于微信/抖音小游戏
存储：浏览器LocalStorage，保存晶核数量、永久强化等级、图鉴解锁状态
美术：原型完全使用内置Polygon2D、GPUParticles2D、ShaderMaterial，无外部PNG贴图

2.整体架构节点分层
MainScene（主游戏场景）
├─ Player 玩家节点（CharacterBody2D）
│  ├─ Polygon2D 菱形晶体外观 + Shader自发光
│  ├─ GPUParticles2D 玩家周身微光粒子
│  └─ PlayerLogic.gd 玩家逻辑：移动、自动攻击、技能管理、血量、瞬闪
├─ MonsterManager 怪物管理器（Node2D）
│  └─ Monster.gd 怪物基类；小晶怪/大晶兽/BOSS继承
├─ SkillSystem 技能系统（Node2D）
│  ├─ SkillManager.gd 管理玩家所有已学习技能、技能等级、技能效果注册
│  └─ 各个技能独立逻辑节点（引力漩涡、晶域、晶盾等）
├─ DropManager 掉落管理器（Node2D）
│  └─ CrystalDrop.gd 晶粒拾取物
├─ EffectManager 特效管理器（Node2D）
│  └─ GPUParticles2D 爆炸碎片粒子、屏幕震动、闪光后处理
├─ UIManager UI管理器（CanvasLayer）
│  ├─ HUD
│  ├─ UpgradePanel（升级3选1弹窗）
│  └─ ResultPanel结算面板
└─ GameLogic.gd 全局游戏管理器：倒计时、游戏状态（菜单/游戏中/结算）、经验管理

3.核心模块详细设计
3.1玩家模块 Player
1.输入：触屏滑动获取目标位置，CharacterBody2D平滑移动跟随目标
2.自动攻击：计时器控制发射晶刺投射物Projectile
3.血量管理，受伤触发屏幕震动
4.瞬闪：按钮触发短距离冲刺，带冷却
5.持有Skill组件，记录所有已习得技能等级

3.2怪物模块 Monster（继承基类）
1.自动寻路：move_toward玩家，持续追踪
2.碰撞检测：接触玩家造成伤害
3.血量归0 → 触发死亡事件，通知EffectManager生成爆炸 + 执行碎裂引爆逻辑
4.死亡生成晶粒掉落物
重要约束：碎裂引爆连锁爆炸逻辑限制最大连锁层数，防止无限递归卡死。

3.3技能系统 SkillManager
组件式架构，每个技能独立逻辑，注册到SkillManager。
升级选择技能时：已有该技能，等级+1；没有则新增技能。
SkillManager每一帧统一驱动所有激活技能。
技能配置：技能ID、名称、描述、每级参数、图标（原型用几何图形代替图标）。

3.4爆炸连锁逻辑伪代码
func spawn_explosion(position, chain_level):
    if chain_level > MAX_CHAIN: return
    生成爆炸粒子特效
    获取爆炸范围内所有怪物
    for monster in 范围内怪物:
        if monster.alive:
            monster.take_damage(爆炸伤害)
            if monster.hp <= 0:
                spawn_explosion(monster.position, chain_level +1)
MAX_CHAIN推荐值：8，控制性能，避免无限连锁爆炸。

3.5存档模块
LocalStorage序列化JSON，保存内容示例：
{
    "crystal_core": 120,
    "permanent_upgrades": {
        "hp": 1,
        "attack": 1,
        "pick_range": 0,
        "start_skill":0
    },
    "unlock_monster": ["小晶怪"]
}
存档时机：每局结算完成自动保存；进入强化面板读取。

3.6游戏状态机，共4种状态
1.MENU：主菜单
2.PLAYING：对局进行中，倒计时运行，怪物持续刷新
3.SETTLE：结算过渡，停止怪物刷新，停止玩家输入
4.UPGRADE_PANEL：升级弹窗，暂停游戏，等待玩家选择技能
升级弹窗弹出时，暂停游戏世界，怪物停止移动，倒计时暂停。

3.7怪物刷新逻辑
随时间动态提升刷怪数量；越靠近180秒，怪物刷新速率越高。
120秒固定触发BOSS生成。
怪物不会在玩家很近的位置生成，避免出生直接贴脸秒杀玩家。

4.Shader 2D自发光晶体shader，给Polygon2D使用，青蓝色发光，边缘高亮
shader_type canvas_item;
uniform vec4 base_color : source_color = vec4(0.1,0.8,0.9,1.0);
uniform float glow_strength : hint_range(0.0,3.0) = 1.2;
void fragment(){
    vec4 col = base_color;
    float dist = length(UV - vec2(0.5));
    col.rgb *= (1.0 - dist);
    col.rgb *= glow_strength;
    COLOR = col;
}
